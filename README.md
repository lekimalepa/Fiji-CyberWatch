# Fiji CyberWatch

## Cyber Threat Intelligence Analytic & Decision-Support Demonstrator

Fiji CyberWatch is a Data Science prototype project showcasing how synthetic cybercrime data can be transformed into valuable insights, geographical summaries, and intelligence-style reporting.

## Project Features

- Synthetic cybercrime dataset generation
- Incident trend analysis
- Dimensional & geographic visualization
- Intelligence Reporting Module
- Interactive dashboards/filters
- Thematic/all classification analysis
- Severity classification analysis
- Reporting delay analysis

## Technology Stack

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Folium

## Data Classification

**Synthetic Data Only**

This application does not use operational law enforcement data.
